# Lowyalty Brandingline storefront

## Goal
Build a polished print-and-branding website for **Lowyalty Brandingline Ltd** that closely follows Almond’s proven structure and shopping flow, while using original Lowyalty wording, imagery, and identity to avoid copying protected brand assets.

## What will be built
- A shared desktop and mobile header with product-category navigation, search, cart, and clear contact access.
- A home page following the reference sequence: product search, category grid, services, company story, completed-work showcase, testimonials, and shop call-to-action.
- A full product catalog with print categories, filter/search controls, product cards, prices, and product detail pages with quantity and common print options.
- A working browser cart with quantity editing, totals, delivery note, and checkout handoff screen.
- Dedicated About, Services, Shop, Samples, Corporate, and Contact pages, each with tailored search/social metadata.
- A contact and quotation form, visible phone/email/location details, and a two-tier footer.
- Responsive mobile navigation and layouts, accessible controls, loading/empty states, and restrained interaction animations.

## Content and visual direction
- Keep Almond’s broad information architecture and high-density print catalog approach.
- Rewrite all copy for Lowyalty Brandingline Ltd and avoid unsupported claims such as Almond’s founding date or client history.
- Use an original red, charcoal, white, and soft-tint design system inspired by the reference, with a legally usable geometric sans-serif font.
- Use original generated print-product imagery initially; the supplied Lowyalty logo and product photos can replace these once uploaded.
- Use sample Kenyan-shilling prices clearly presented as starting prices until the real catalog is connected.

## Technical details
- Implement separate TanStack routes for all major pages and a dynamic product route.
- Keep catalog data in a reusable typed module so real Shopify products can replace samples without redesigning the site.
- Persist the cart locally for this storefront prototype; no customer or order data will be stored yet.
- Add route-specific title, description, Open Graph, and Twitter metadata.
- Verify the result in desktop and mobile browser sizes, including menu, search, product selection, cart updates, and forms.

## Checkout limitation
A real checkout for physical print products requires the Shopify setup that was skipped. The site will include the complete storefront and cart experience, with checkout clearly marked as awaiting store connection rather than pretending to take payment.
